# Fontes de arte — Magic Castle

Receitas e fontes de autoria pertencem ao **jogo**, não ao catálogo compartilhado do A7. O arquivo `wizard/pixel_character_wizard_mini_01.json` é uma cópia inicial fixada da receita de mago do A7 para tornar a futura separação reproduzível.

O A7 Forge 2D é usado **somente no build** para gerar PNGs. O navegador carrega apenas arte exportada. Na migração, instalar o A7 como ferramenta externa, pacote versionado ou copiar somente os outputs licenciados, sem importar a árvore de fontes A7 para o projeto do jogo.

Não atualizar essa receita automaticamente a partir do A7: qualquer mudança visual deve ser revisada, comparada e aprovada explicitamente.
