# Interface original — Terminal de bairro

`brand.svg` e os 41 símbolos em `icons.svg` foram desenhados diretamente em SVG para o Lan House Simulator. São vetores locais, sem imagens de terceiros ou dependências externas.

A marca representa um CRT com cursor de terminal. Os símbolos usam `viewBox 0 0 24 24`, traço 1,7 e cor herdada da interface. Labels de botões continuam como texto acessível; SVGs decorativos ficam fora da leitura assistiva.

Paleta, uso e validação estão em `../../docs/VISUAL_IDENTITY.md`. Estes são recursos de interface integrados por solicitação do criador; não equivalem à promoção de sprites de personagens.
